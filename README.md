# Free Web Tools

Nine small, free, no-signup utilities for anyone building or running a website — SEO checks, generators, and speed/uptime diagnostics. All live and open on [tools.it-service-online.ru](https://tools.it-service-online.ru/); this repo is just the index/landing point for them on GitHub.

| Tool | What it does | Try it |
| --- | --- | --- |
| Uptime Checker | Checks whether a site is reachable and how fast it responds | [→](https://tools.it-service-online.ru/uptime) |
| SEO Audit Express | Instant check for basic meta tags (Title, Description, H1) | [→](https://tools.it-service-online.ru/seo-audit) |
| Meta Tag Generator | Generates an optimized Title + Description for a target keyword | [→](https://tools.it-service-online.ru/meta-generator) |
| Robots.txt Generator | Builds a correct robots.txt for Google and Yandex crawlers | [→](https://tools.it-service-online.ru/robots-generator) |
| Sitemap.xml Generator | Builds a sitemap.xml with configurable update frequency | [→](https://tools.it-service-online.ru/sitemap-generator) |
| Server Speed Checker | Measures server response time (TTFB) | [→](https://tools.it-service-online.ru/speed-check) |
| Competitor Analysis | Compares meta-tag content against competitor sites | [→](https://tools.it-service-online.ru/competitors) |
| Landing Page Structure Generator | Interactive tool for planning a high-conversion landing page | [→](https://tools.it-service-online.ru/structure-generator) |
| Favicon Generator | Generates a site favicon from text or emoji, no image editor needed | [→](https://tools.it-service-online.ru/favicon-generator) |

No login, no paywall, no API key — every link above opens a working tool directly.
